# Question deck

Single file HTML app that shows one open ended question at a time for two people to trade back and forth. No build step, no dependencies, no server.

**Live:** https://sdiasuez11.github.io/question-deck/

## What it does

- 155 questions tagged by vibe and topic
- Four tabs: Playful, Mixed, Deep, Music
- Star to save a question, saved list has its own view
- Pass retires a question permanently, next just marks it seen
- Reshuffle brings back everything except passed questions
- Two column layout on wide screens, deck and saved list side by side; single column with a toggle below ~860px
- State persists per device in `localStorage`
- Keyboard: space or right arrow advances, `s` saves (ignored while focus is in a text input)
- Font is embedded, so the page makes zero external requests

## Question bank

| Tag | Count |
|---|---|
| playful | 85 |
| deep | 70 |
| music (cross tagged onto both) | 25 |

Music questions show up in Playful, Mixed, and Deep rounds as well as their own tab. Music is a topic filter, not a fourth vibe.

## Architecture

```
RAW[]  -> [text, vibe, topic?]
BASE   -> RAW mapped to {id, text, vibe, topic}
state  -> {vibe, generated[], used[], retired[], saved[]}
pool()  filters BASE + generated by matches(q, vibe), minus used and retired
draw()  picks at random from pool, pushes to used, persists, renders
```

Storage falls back in this order: `window.storage` (Claude artifact runtime), then `localStorage` (everywhere else), under the key `question-deck-nocturne-v1`.

## Design

Dark palette (Coolors `264653-2a9d8f-e9c46a-f4a261-e76f51`, adapted): `#101d24` ground, `#1a3039` card surface, sand `#e9c46a` accent, teal `#2a9d8f` accent-2. Newsreader for all type, single variable-weight woff2 file, weights 300-600 synthesized from it. Cards carry a three-layer texture: SVG fractal-noise grain blended `overlay`, a teal glow top-left, and a soft top-light gradient. Full CSS custom properties are in `index.html`'s `:root` block.

Redesign shipped 2026-08-10, replacing the original honey/paper palette. `setup.html` was intentionally left on the old palette, it's out of scope for the redesign and still functionally correct; a visual mismatch between the two pages is the known tradeoff.

## Known constraints

The "Write new ones" button only appears inside a runtime that exposes `window.claude.complete` (the Claude artifact preview). On the hosted version it hides itself and the deck runs on its 155 questions. Making generation work here would need a small backend holding a key, and per the design handoff, an API key should never ship to the client.

## On a phone

Illustrated walkthrough: https://sdiasuez11.github.io/question-deck/setup.html

Open the link in Safari, then Add to Home Screen. The PWA meta tags make it launch full screen with its own icon, titled "Questions". Saved stars and passed questions live in that device's `localStorage`, so each phone keeps its own deck state.

The deck carries a discreet footer link to the setup page, and hides that link once it's running standalone from the home screen.

## Adding questions

Append to `RAW` in `index.html`:

```js
["Your question here","playful"],
["Another one","deep","music"],
```

A new topic tab needs the tag on the questions, an entry in the `opts` array inside `renderVibes`, and a branch in `matches()`. The grid is four columns, a fifth tab means changing the CSS and shortening the labels.
